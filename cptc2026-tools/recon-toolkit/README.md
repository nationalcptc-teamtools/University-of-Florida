# recon-toolkit

Small enumeration scripts for the attack box. Enumeration only, nothing is changed on a target.

- `setup.sh` — install the usual tools (`./setup.sh`, or `--list` to preview).
- `cptc-triage.sh <range>` — network service triage built on nmap.
- `cptc-enum.sh` — local enumeration on a Linux host.
- `cptc-web.sh <url>` — basic checks against a web target.
- `cptc-winenum.ps1` — local enumeration on a Windows host.

Run the active ones only in scope.
